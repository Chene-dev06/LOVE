# Tbghini? 💗

A small React/Vite love-message website with three screens:
1. “Tbghini?” with playful LA / WAH buttons.
2. “T9bel message te3y?” with an expressive avatar and escalating No reactions.
3. A personal message with a “Haja for you” button that sends kisses floating across the page.

## Run locally

You need Node.js installed.

```bash
npm install
npm run dev
```

Open the local address printed by Vite (usually http://localhost:5173).

## Build for publishing

```bash
npm run build
```

The production website will be created in the `dist` folder.

## Customize

- Edit the text in `src/main.jsx`.
- Change colors, fonts, spacing, and animations in `src/style.css`.
- The Google Fonts import needs an internet connection; the site still works with fallback fonts if unavailable.
